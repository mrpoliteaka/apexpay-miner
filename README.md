# ApexPay Miner — First Working Prototype

This is a mobile-first static web prototype designed for deployment on Vercel.

## Included
- Sign-up/demo login
- Local browser account state
- Home dashboard
- Simulated mining timer
- Simulated NGN balance and mining history
- Withdrawal page with withdrawals disabled
- Profile page
- Responsive UI
- No real payments, bank details, withdrawal codes, or money transfers

## Deploy on Vercel
1. Extract this folder.
2. Put the folder in a GitHub repository.
3. Import the repository into Vercel.
4. Vercel can deploy it as a static site; no build command is required.

## Important
The displayed mining balance is a simulation only. It is not real money and cannot be withdrawn.
For a production financial product, use a secure backend/database, a legitimate payment provider, authentication, audit logging, and applicable legal/compliance review.
